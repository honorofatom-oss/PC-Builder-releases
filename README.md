# PC-Builder — файлы релизов

Здесь лежат только готовые сборки приложения PC-Builder для Windows:

* `PC-Builder Setup <версия>.exe` — установщик;
* `PC-Builder <версия>.exe` — portable-версия;
* `latest.yml` — сведения для автообновления (по нему приложение узнаёт о новой версии).

Исходного кода в этом репозитории нет: он в закрытом репозитории, потому что
содержит рабочие настройки проекта.

Сайт: https://pc-builder-atom.ru
